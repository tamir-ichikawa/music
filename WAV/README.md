# WAV

全614本の合成演奏を作曲家別に整理しています。WAV本体はReleasesにあります。各作曲家のフォルダから個別またはZIPでダウンロードできます。

複数のZIPがある作曲家は、従来分と今回追加分に分かれています。すべて取得するとその作曲家の全収録音声が揃います。ZIP内は WAV/作曲家名/ で統一しています。
