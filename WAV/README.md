# WAV

全414本の合成演奏を作曲者別に整理しています。各作曲者のフォルダで、1曲ずつ、または一括ZIPでダウンロードできます。ZIPを展開すると WAV/作曲者名/ に実音声が並びます。

WAV本体はファイル容量の都合でGitHub Releasesに保存しています。このフォルダにはダウンロード目録が入っています。
