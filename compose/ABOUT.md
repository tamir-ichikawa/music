# 制作・公開範囲

参照作家の作風を分析し、新しい動機・構成・編成で制作したオリジナル器楽曲です。古典の原曲MIDI・録音の転載ではなく、各作家本人の作品として扱わないでください。Codexを用いた作曲支援とプログラムによるMIDI生成を行っています。

43作家×３曲の129曲に、以前のドビュッシー参考作品７曲を加えた136曲。DBY-007は現在版r02です。旧版、制作途中のデータ、ローカル環境のログは含めていません。

WAVはFluidSynth 2.6.1とMuseScore Generalによる合成演奏。48 kHz / 24 bit / stereo。楽器音源本体は配布していません。[音源クレジットと通知](credits/SOUNDFONT_NOTICE.txt)を保持しています。

今回の129曲はMIDIの再読込、音符の対応、楽器音域、単旋律パートの同時発音、テンポ積算、３〜４分の尺、WAVの非無音・クリッピング・終端フェードを検証済みです。既存７曲も従来の検証に加え、公開時にMIDIと音声ヘッダ・尺を再確認しました。全曲の聴感による芸術性評価、実演者による運指確認を完了したという意味ではありません。

元資料は作家ごとに量・版・編曲の有無が異なります。資料の少ない作家について全作品の様式を再現したものではありません。独自の研究・制作としてお聴きください。
