# MIDI

全414ファイルを作曲者別に保存しています。各曲の「ダウンロード」を押すとMIDIを取得できます。全件はリポジトリ上部の Code → Download ZIP でも取得できます（WAV本体は含みません）。

楽器・パート単位のトラック構成を保持。ピアノの左右手は同じ楽器の1トラック、合奏はパート別です。テンポ専用トラックが別に含まれる場合があります。
